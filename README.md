# GrafikKomputer2

Demo grafika komputer berbasis web yang menampilkan animasi kucing 3D menggunakan Babylon.js.

## Isi Project

- Scene 3D dengan kamera orbit
- Pencahayaan hemispheric dan directional
- Shadow mapping
- Model kucing tersusun dari primitive mesh
- Material dan animasi berbasis JavaScript

## Menjalankan

Project ini berupa static web app. Buka `index.html` melalui static server agar asset CDN Babylon.js dapat dimuat dengan konsisten.

Contoh:

```bash
python -m http.server 8000
``

Lalu buka http://localhost:8000.

## Teknologi

- HTML
- CSS
- JavaScript
- Babylon.js CDN

## Status

Project pembelajaran untuk eksplorasi scene, mesh, material, kamera, lighting, dan animasi 3D.
